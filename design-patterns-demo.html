🎯 행위 패턴이란?

행위 패턴(Behavioral Pattern)은 여러 객체들의 상호 작용과 책임 분담에 관한 디자인 패턴입니다.

쉽게 말하면, 객체들이 서로 어떻게 협력하고 행동할지를 효율적으로 정하는 방법이에요!

⚽ 비유: 축구팀에서 포지션별 역할을 나누는 것처럼, 프로그램 객체들도 역할을 나누고 협력해야 합니다. 행위 패턴은 이런 팀워크를 잘 조직하는 방법들을 제공합니다!

🚀 Strategy 패턴 (전략 패턴)

왜 필요할까?

어떤 작업을 수행하는 여러 가지 방법(알고리즘)이 있을 때, if-else 조건문이 잔뜩 생기는 것을 방지합니다.

전략 패턴은 각 방법을 별도 클래스로 만들고, 필요할 때 선택해서 사용하는 패턴입니다.

🎒 실생활 비유

학교에 가는 여러 가지 방법이 있어요: 걸어가기, 버스 타기, 자전거 타기, 자동차 타기...

상황에 따라 이 중 하나를 선택할 수 있죠!

Python 코드 예제

# 전략 클래스들 정의
class WalkStrategy:
    def travel(self, destination):
        print(f"{destination}까지 걸어가는 중이에요.")

class BusStrategy:
    def travel(self, destination):
        print(f"{destination}까지 버스를 타고 가는 중이에요.")

# 사람(Person) 클래스 정의
class Person:
    def __init__(self, name, strategy):
        self.name = name
        self.strategy = strategy  # 현재 전략

    def go_to_school(self):
        print(f"{self.name}: ", end="")
        self.strategy.travel("학교")

# 사용 예시
student = Person("철수", WalkStrategy())
student.go_to_school()  # 철수: 학교까지 걸어가는 중이에요.

student.strategy = BusStrategy()  # 전략 변경!
student.go_to_school()  # 철수: 학교까지 버스를 타고 가는 중이에요.
💡 포인트: 새로운 이동 방법을 추가해도 Person 클래스는 수정할 필요가 없어요! 새로운 Strategy 클래스만 추가하면 됩니다.

🔄 State 패턴 (상태 패턴)

왜 필요할까?

객체의 상태에 따라 행동이 달라져야 할 때, if-elif-else 문이 여러 곳에 생기는 것을 방지합니다.

상태 패턴은 상태를 클래스로 만들어, 상태가 바뀌면 자동으로 행동도 바뀌게 하는 패턴입니다.

📅 실생활 비유

초등학생의 평일과 주말 생활 패턴이 완전히 다르죠?

  • 평일 상태: 아침 일찍 일어나서 학교에 가서 공부
  • 주말 상태: 늦잠 자고 집에서 쉬거나 놀기

행동하기 버튼을 눌러보세요!

Python 코드 예제

# 상태 클래스들 정의
class WeekdayState:
    def act(self):
        print("학교에 가서 공부해요.")

class WeekendState:
    def act(self):
        print("집에서 쉬거나 놀아요.")

# 학생(Kid) 클래스 정의
class Kid:
    def __init__(self, name):
        self.name = name
        self.state = WeekdayState()  # 초기 상태

    def do_something(self):
        print(f"{self.name}: ", end="")
        self.state.act()

    def change_state(self, new_state):
        self.state = new_state

# 사용 예시
child = Kid("영희")
child.do_something()  # 영희: 학교에 가서 공부해요.

child.change_state(WeekendState())  # 상태 변경!
child.do_something()  # 영희: 집에서 쉬거나 놀아요.
💡 포인트: 새로운 상태를 추가해도 Kid 클래스는 거의 수정할 필요가 없어요! 새로운 State 클래스만 추가하면 됩니다.

⚖️ Strategy vs State 패턴 비교

두 패턴 모두 행동을 유연하게 바꿀 수 있게 하지만, 의도와 사용 방식이 다릅니다!

구분 Strategy 패턴 (전략) State 패턴 (상태)
목적 여러 알고리즘 중 하나를 선택 상태에 따라 자동으로 행동 변경
변경 주체 외부(클라이언트)에서 전략을 선택 객체 내부에서 상태가 바뀜
관계 각 전략은 독립적 상태들은 서로 연결되어 전환됨
예시 이동 수단 선택 (걷기, 버스, 자전거) 요일 변화 (평일 ↔ 주말)
비유 오늘 어떤 옷을 입을까 고르기 신호등이 시간에 따라 자동으로 바뀌기
🎯 기억하기:
Strategy = "내가 방법을 선택한다" (외부 선택)
State = "상태가 바뀌면 행동도 바뀐다" (내부 변화)

🎓 정리

왜 이런 패턴을 배울까?

  • ✅ 코드가 깔끔해집니다 (if-else 문 감소)
  • ✅ 새로운 기능 추가가 쉬워집니다
  • ✅ 기존 코드를 수정하지 않아도 됩니다
  • ✅ 버그가 줄어듭니다
  • ✅ 다른 개발자가 이해하기 쉽습니다
