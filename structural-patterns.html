📚 구조 패턴이란?

구조 패턴(Structural Pattern)은 클래스나 객체들을 효율적이고 유연하게 조직하여 더 큰 구조를 만드는 방법을 제공하는 디자인 패턴입니다. 코드의 재사용성과 유연성을 높여주어 유지보수를 쉽게 만들어줍니다.

🍔 데코레이터 패턴 (Decorator Pattern)

데코레이터 패턴은 객체에 새로운 기능을 추가하고 싶을 때, 래퍼(wrapper) 객체로 감싸서 원래 객체에 동적으로 책임을 덧붙이는 패턴입니다. 상속으로 클래스를 늘리지 않고도 객체의 기능을 확장할 수 있습니다.

🔌 어댑터 패턴 (Adapter Pattern)

어댑터 패턴은 서로 맞지 않는 인터페이스를 지닌 객체들이 함께 동작할 수 있도록 중간에서 변환을 해주는 구조 패턴입니다. 객체 A의 사용 방식을 객체 B가 기대하는 방식으로 "통역"해주는 역할을 합니다.

⚖️ 데코레이터 vs 어댑터

두 패턴 모두 객체를 감싼다는 공통점이 있지만, 목적과 기능이 다릅니다.

구분 데코레이터 패턴 🍔 어댑터 패턴 🔌
목적 객체에 새로운 기능 추가 서로 다른 객체들을 인터페이스 변환으로 연결
인터페이스 원래 객체와 동일한 인터페이스 유지 다른 인터페이스로 변환
중첩 사용 여러 개를 겹겹이 쌓아 적용 가능 보통 한 번만 변환
예시 샌드위치에 토핑 추가하기 전기 플러그 어댑터, 통역사
사용 시기 런타임에 동적으로 기능 추가가 필요할 때 호환되지 않는 코드를 연결해야 할 때

💡 핵심 요약

✅ 데코레이터 패턴:

  • 상속 없이 객체의 기능을 동적으로 확장
  • 인터페이스는 그대로, 내부 동작만 추가
  • 여러 데코레이터를 자유롭게 조합 가능

✅ 어댑터 패턴:

  • 서로 다른 인터페이스를 가진 객체들을 연결
  • 기존 코드 수정 없이 호환성 확보
  • 통역사나 변환기 역할

🎯 기억하세요: 데코레이터는 "기능 추가", 어댑터는 "인터페이스 변환"!
