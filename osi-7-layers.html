OSI(Open Systems Interconnection) 모델은 네트워크 통신을 7개의 논리적 계층으로 나눈 표준 모델입니다.

각 계층은 특정한 기능을 담당하며, 계층화를 통해 복잡한 네트워크 통신을 이해하기 쉽게 만듭니다.

💻 응용 계층 (Application Layer)

사용자와 가장 가까운 계층으로, 사용자가 직접 상호작용하는 응용 프로그램들이 동작하는 계층입니다.

주요 기능

✅ 사용자 인터페이스 제공

✅ 네트워크 서비스 제공 (이메일, 파일 전송, 웹 브라우징)

✅ 응용 프로그램 간 데이터 교환

대표 프로토콜

HTTP/HTTPS FTP SMTP DNS SSH Telnet

실생활 예시

🌐 웹 브라우저로 웹사이트 접속

📧 이메일 프로그램으로 메일 송수신

📁 FTP 클라이언트로 파일 전송

🔄 표현 계층 (Presentation Layer)

데이터의 형식을 변환하고, 암호화/복호화를 수행하는 계층입니다. 서로 다른 시스템 간의 데이터 표현 방식을 일치시킵니다.

주요 기능

✅ 데이터 형식 변환 (인코딩/디코딩)

✅ 데이터 암호화 및 복호화

✅ 데이터 압축 및 해제

대표 프로토콜/포맷

SSL/TLS JPEG MPEG ASCII EBCDIC

실생활 예시

🔐 HTTPS로 웹사이트 접속 시 SSL/TLS 암호화

🖼️ 이미지 파일 포맷 변환 (PNG → JPEG)

📦 파일 압축 (ZIP, GZ)

🔗 세션 계층 (Session Layer)

두 시스템 간의 대화(세션)를 관리하고 제어하는 계층입니다. 연결의 설정, 유지, 종료를 담당합니다.

주요 기능

✅ 세션 설정, 유지, 종료

✅ 데이터 교환의 동기화

✅ 대화 제어 (반이중, 전이중)

대표 프로토콜

NetBIOS RPC PPTP SSH

실생활 예시

🎮 온라인 게임 세션 유지

💬 화상 회의 연결 관리

🏦 인터넷 뱅킹 로그인 세션

🚚 전송 계층 (Transport Layer)

종단 간(End-to-End) 데이터 전송을 담당하며, 신뢰성 있는 데이터 전송을 보장합니다.

주요 기능

✅ 데이터 분할 및 재조립

✅ 흐름 제어 및 오류 제어

✅ 포트 번호를 통한 프로세스 식별

✅ 연결 지향(TCP) 또는 비연결(UDP) 서비스

대표 프로토콜

TCP UDP SCTP

실생활 예시

📦 TCP: 파일 다운로드 시 데이터 무결성 보장

🎥 UDP: 실시간 스트리밍 (YouTube, Netflix)

🎮 UDP: 온라인 게임 (빠른 응답 속도 필요)

🗺️ 네트워크 계층 (Network Layer)

데이터를 목적지까지 안전하고 효율적으로 전달하기 위한 경로 설정(라우팅)을 담당합니다.

주요 기능

✅ 논리적 주소 지정 (IP 주소)

✅ 라우팅 (최적 경로 결정)

✅ 패킷 포워딩

✅ 서로 다른 네트워크 간 통신

대표 프로토콜

IP (IPv4/IPv6) ICMP ARP OSPF BGP

실생활 예시

🌍 서울에서 뉴욕 서버로 데이터 전송 시 경로 설정

📍 IP 주소를 통한 기기 식별

🔍 라우터가 패킷의 최적 경로 결정

📡 데이터 링크 계층 (Data Link Layer)

직접 연결된 두 노드 간의 신뢰성 있는 데이터 전송을 담당합니다. 물리 계층의 오류를 감지하고 수정합니다.

주요 기능

✅ 물리적 주소 지정 (MAC 주소)

✅ 프레임 구성

✅ 오류 검출 및 수정

✅ 흐름 제어

✅ 매체 접근 제어 (MAC)

대표 프로토콜/기술

Ethernet Wi-Fi (802.11) PPP HDLC MAC

실생활 예시

🔌 이더넷 케이블로 연결된 PC와 라우터 간 통신

📶 Wi-Fi 공유기와 스마트폰 간 무선 연결

🏷️ MAC 주소를 통한 기기 식별

⚡ 물리 계층 (Physical Layer)

실제 물리적 매체를 통해 비트 스트림을 전송하는 계층입니다. 전기적, 기계적 특성을 정의합니다.

주요 기능

✅ 비트를 전기 신호로 변환

✅ 물리적 연결 설정 및 유지

✅ 전송 매체 및 토폴로지 정의

✅ 데이터 전송률 결정

대표 기술/장비

케이블 (UTP, 광섬유) 허브 리피터 RS-232 USB

실생활 예시

🔌 랜 케이블을 통한 전기 신호 전송

💡 광섬유를 통한 빛 신호 전송

📡 무선 주파수를 통한 전파 전송

📊 데이터 전송 흐름 시각화
